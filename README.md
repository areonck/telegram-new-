# Telegram Interview Orchestrator

Скелет системы для автоматизированного текстового "собеседования" в групповом чате Telegram с несколькими управляемыми аккаунтами. Основано на Telethon (пользовательские аккаунты) и aiogram (админ-бот).

## Возможности (заложены в архитектуру)
- Хранение конфигурации аккаунтов, чатов, вопросов, ответов ботов, сценариев напоминаний в БД (SQLite по умолчанию).
- Админ-бот с командами для добавления чатов, привязки аккаунтов, просмотра статуса и логов.
- Планировщик таймингов: отправка вопросов, ответов ботов с задержками и индикатором "печатает", напоминания пользователю при отсутствии ответа.
- Поддержка нескольких чатов (2–4) одновременно через отдельные сессии.

## Быстрый старт
1. Создайте `.env` на основе `.env.example` (не вставляйте реальные токены в репозиторий):
   ```bash
   cp .env.example .env
   ```
   Заполните `TELEGRAM_API_ID`, `TELEGRAM_API_HASH`, `ADMIN_BOT_TOKEN`.

2. Установите зависимости (Python 3.11+). На macOS используйте `python3`:
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

3. Инициализируйте базу (важно запускать из корня репозитория, чтобы модуль `app` был виден):
   ```bash
   python scripts/init_db.py
   ```

4. Запустите админ-бота:
   ```bash
   python -m app.admin_bot
   ```

## Структура
- `app/config.py` — настройки через Pydantic.
- `app/db.py` — подключение к БД и сессии.
- `app/models.py` — ORM-модели: аккаунты, чаты, вопросы, ответы ботов, сценарии напоминаний, сессии, события, настройки.
- `app/services.py` — базовые операции с БД и сервисные функции.
- `app/telegram_clients.py` — менеджер Telethon-клиентов и логин с кодом.
- `app/interview_engine.py` — движок интервью и тайминги (включая напоминания).
- `app/admin_bot.py` — каркас админ-бота на aiogram с основными командами.
- `scripts/init_db.py` — создание таблиц.

## Ключевые команды админ-бота (минимальный набор)
- `/start` `/help` — справка.
- `/add_chat <chat_id>` — добавить чат.
- `/list_chats` — список чатов.
- `/add_account` — выбор роли (главный/бот).
- `/bind <phone> <session_path>` — сохранить аккаунт (главный/бот), путь к session-файлу.
- `/code <account_id> <12345>` — принять код для логина (интеграция с Telethon в менеджере клиентов).
- `/list_accounts` — список привязанных аккаунтов.
